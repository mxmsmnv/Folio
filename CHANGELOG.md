# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-27

### Added
- Initial release of Folio personal organizer for ProcessWire.
- Dashboard with icon-chip statistics, quick-add buttons, and summary cards.
- Projects, Sprints, and Tasks (with Kanban board view and status/priority labels).
- Calendar and recurring event rules.
- Contacts directory with photos, roles, companies, and birthday tracking.
- Places with visit status, map coordinates, and photo attachments.
- Links and bookmarks management.
- Goals and Roadmap vertical milestone timeline.
- Historical Timeline feed of completed items.
- Configurable module settings and CLI seed script (`src/Cli/seed.php`).
